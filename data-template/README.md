# My CatchUp data

The people I want to keep in touch with, one Markdown file each in [`people/`](people).
Read and written by the [CatchUp](https://github.com/geno-whirl/CatchUp) app — and by AI
assistants, see [AGENTS.md](AGENTS.md).

**Keep this repository private.**

- New person: copy [`people/_template.md`](people/_template.md) to `people/first-last.md`.
- Log a catch-up: add a `### YYYY-MM-DD · Call` entry at the top of the person's `## Log`.
- Things to bring up next time: `- [ ] …` lines; tick them with `- [x]`.
